# The Weimar Republic · 电子版规则工作台

当前版本 **0.12**，包含浏览器热座和Steam Lobby桌面联机。已实现 **危机时代 #1–52、黄金时代 #53–112、衰落时代 #113–151 全部牌效**，共151个事件、154种可执行牌面（含3种选举牌面），四个历史剧本均已接通。联机代码已完成模拟多客户端验证，真实Steam双机验收仍待进行。

换电脑继续开发请先看[仓库启动说明](../README.md)与[开发交接说明](docs/development-handoff.md)。克隆后安装依赖即可启动，运行素材已包含在仓库中。

开发顺序是先盘点全牌需求、搭通用框架，再批量实现牌效。现在流程核心已接入对局，支持跨阵营选择、条件和循环、事件授予行动、实际结果驱动后续效果、持续规则、暂停保存与命令回放。界面仍以规则验证为主。

## 启动

需要 Node.js 24+ 和 pnpm；本机依赖已安装。也可运行项目根目录的 `start.ps1`，自动使用已配置运行时。

```powershell
cd 'F:\CODEX\WEIMAR项目组\weimar'
pnpm dev
```

打开终端给出的本机地址，通常为 <http://127.0.0.1:5173/>。

```powershell
pnpm test
pnpm typecheck
pnpm build
pnpm preview
pnpm audit:cards
```

Steam联机需要安装并登录Steam，运行`pnpm desktop`打开桌面版。暂用测试AppID 480；建房、选阵营、准备和开始均在顶部Steam面板操作。`pnpm desktop:pack`生成Windows桌面包，`pnpm steam:check`单独诊断原生SDK初始化。详见[Steam联机说明](docs/steam-multiplayer-0.8.md)。

## 棋盘界面

默认打开原版中文棋盘，按规则书第48页的摆局形式叠加独立的原版 token 贴图；无印刷面的白色棋子、黑色方块和影响力方块按实物形状显示。26个地区的影响力和部队、轨道标记、议会控制与持续事件均随真实局面更新。点地区查看详情；进行有地区目标的行动时，点金色边框地区可选目标，再点击执行。支持适应窗口、100%–250%缩放和专注棋盘。

对局、撤销及存档入口收进“对局与存档”；手牌在下方，玩家区使用四张原版垫板，显示团结、立场、经济影响力和库存可用性；点击顶部阵营名可直接展开。已移出游戏的部队单独列出。见[0.10玩家垫板说明](docs/player-mats-0.10.md)。详见[棋盘UI说明](docs/tabletop-ui-0.9.md)。

0.11增加可用棋子绿框、共享MCS左右半框、固定人口空位，以及即时领导／占据标记。地区详情同时显示军力和军事优势。见[棋盘状态说明](docs/board-status-0.11.md)。

0.12在底部PV规使用原版四方标记实时显示全国总PV；右上角用8区域×4阵营的实时PV表替换印刷选举区域说明，金色星标指出最高值（并列同标）。全国总PV含势头、中产支持等修正，随行动、撤销及联机状态更新。见[实时PV说明](docs/live-pv-0.12.md)。

## 完整战役

顶部选择“共和国的命运 · 1919—1933”，新建对局并确定年度顺序。按正式剧本9.6布置，每方7张危机牌；1924年发9张黄金牌、1930年发6张衰落牌，减去各方留牌惩罚。每年不会自动补牌。1933年终先对所有阵营结算留牌惩罚，再按联盟是否留牌决定直接胜利或最终选举。详见[战役说明](docs/campaign-0.6.md)。

也可选择以下历史剧本，详见[0.7剧本说明](docs/scenarios-0.7.md)：

| 剧本     | 年代      | 本批接入                                                   |
| -------- | --------- | ---------------------------------------------------------- |
| 革命时代 | 1919—1923 | 全局一次额外选举、反动不限于进步、终局军事优势等PV修正     |
| 新希望   | 1924—1933 | 独立地图和棋子布局、每方9张黄金牌、1930换时代              |
| 黑日升起 | 1928—1933 | 预置5张持续事件、每方3张黄金牌、固定务实立场且保留事件前置 |

## 直接测试卡牌

顶部选择“牌效实验局”，选一张#1–151并新建对局。指定牌在联盟手牌首位；可勾选“预置前置事件”。确定年度顺序，选择“先事件，后2行动”；出现第48条时允许事件结算。侧栏按实际决定者提示选择，所有赠送行动结束后保留正常的2次行动，除非事件已使对局结束。

实验局启用标准立场（-3民主、0务实、+3革命），使用教程地图，便于检验标准牌效与持续规则，**不是正式历史剧本**。黄金牌从1924年开始，衰落牌从1930年开始。跨时代完整流程在历史剧本中启用；革命时代按自己的结束年份在1923年终局。

“开发测试局”使用固定牌序；“正式教程牌库”使用53张危机牌、每方5张。两者遵循教程9.2：固定务实立场、忽略事件前置，并在1923年末终局。

浏览器自动保存；导入导出保存开局参数和命令，撤销、重做、刷新都重放同一规则路径。0.8沿用0.7存档格式和存储键；已验证0.6开局和完整战役回放一致。旧0.1–0.5存档按新版规则尝试迁移，不保证旧选择ID或结算结果完全兼容。Steam联机单独保存：房主执行规则，每名玩家仅接收自己的手牌和公开局面；联机时禁用单人撤销和本地重开。
