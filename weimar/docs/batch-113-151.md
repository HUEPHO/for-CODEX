# 衰落时代 · 0.5

完成衰落时代 #113–151 的39个事件。现在三个时代 #1–151 的事件和3种选举牌面全部可执行，共154种牌面。实验局可指定任意事件；衰落牌从1930年开始，仍使用教程地图和标准立场，不等同于正式历史剧本。

## 框架扩展

沿用现有事件流程、效果队列、赠送行动和命令回放，仅补本批牌所需能力：提前选举、立即宣告胜利、永久移除第48条、国会议席使用次数、杠杆替换、从地图调动国防军，以及不带附加弃牌步骤的随机拿牌。

当前PV查询直接复用选举计算，不转让选票、不更新议会控制、不消耗随机数。#117则执行真正的地区和全国选举：刷新地区控制、解除柏林锁定、判定胜负；联盟获胜时刷新未永久移除的第48条和国会议席，完成清场后继续原回合。它不推进时间轴，也不消耗本轮已预约的普通选举。

## 规则依据与解释

参考用户中文牌图、TTS存档引用的英文衰落牌图、规则书6.0／6.1／7.5／7.6及[官方勘误](https://docs.google.com/document/d/1Xg47YYhJ-67k8ZAl3v5WkOgiWI7jx1o_NaR_ojfNbnQ/edit)（2026-10-16）。英文原图为 `reference/tts-decline-english.png`；来源、网格及哈希见 `reference/decline-english-source.json`。未执行附件Lua。

- **#121中英数量不同**：中文图在NSDAP有momentum时写1个地区，英文图写2个。本实现采用英文原牌的2个；中文原始素材保持不改，文本摘要和规则说明注明差异。
- **#135采用的解释**：原牌先写移除NSDAP，再写RC持有momentum时放置RC；没有使用替换措辞。规则6.0禁止同一行动步骤在同地既移除又放置影响力，现有勘误未列本牌例外。因此当前顺序执行：实际移除后不能在巴伐利亚补放；没有移除且RC持有momentum时可以放置。这是依据通则采用的解释，不宣称获得作者单独裁定。若以后确认本牌允许例外，只需调整该模板，不改变全局限制。
- #129的Supremacy指军力占据，不能用仅有驻军或影响力领导代替；干部和军力占据重叠时只算一个地区。
- #137补偿按实际移除的不同地区计算，同地移除多个SA只补偿一次，选择零则没有补偿。干部必须可用且该地不存在任何阵营干部。影响力仍受人口等通则限制。
- #141替换操作内部允许在同地连续替换两个，仍不能绕过此前独立行动的放置／移除历史，也不能绕过暗杀限制。
- #119取消后，第48条仍永久移除，之后普通或提前选举均不会将其恢复。#124首次使用右翼议席后记为已用一次，第二次耗尽；转交时保留使用状态，明确刷新或选举刷新时清零。

## 验证与边界

`tests/decline-batch.test.ts`新增49项专项测试；逐牌和两组固定种子分支遍历扩展到151个事件。全套372项测试、类型检查及生产构建通过，浏览器验证了#117选举后回到原回合、#137实际移除后的补偿及满人口跳过、中途刷新、撤销和重做。结果见[规则覆盖](rules-coverage.md)。

全部牌效接入不等于完整战役完成：完整时代切换、时代补牌、留牌惩罚与另外4个历史剧本尚待实现，UI仍为本机热座规则工作台。实验局只预置必要持续事件，不模拟完整历史局面。
