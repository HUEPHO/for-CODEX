# 棋盘状态与高光 · 0.11

## 可用性

棋盘轨道上的可取棋子、垫板可用库存及未使用的议会控制牌加高光绿边框；锁定棋子不亮。进步／反动之间的共享中产支持按两侧分别判断：左半框代表联盟／KPD可取，右半框代表NSDAP／RC可取，两侧可取时形成完整绿框。垫板上的中产支持可供移动行动使用，也显示绿框。

绿框表达规则中的供应可用性；具体行动仍受阵营、回合、前置条件和合法目标限制。已经部署在进步、反动和经济轨道的杠杆不属于供应，不加绿框。金色地区框继续表示当前所选行动的合法目标。

## 地区状态

- 每个地区绘制固定的人口槽位。已占用位置显示阵营方块，其余显示半透明白色虚线方块；满员后空位消失，总槽位数不变。
- 有唯一影响力领先者时，PV位置以原版阵营徽记作底图，并重绘PV数字。并列或无影响力时不显示领导徽记。
- 地区底边的阵营色条表示驻军占据，可同时有多个阵营；白色内线表示唯一军事优势。干部、罢工等功能标记不计为占据。
- 地区详情增加容量条、领导者和各阵营驻军军力。军事优势并列时不指定胜者。
- 议会控制仍按选举结果变化，不随影响力领先者改变。

所有状态都从当前公开GameState派生，每次行动、事件、待处理选择、撤销／重做或联机快照到达时重绘。没有缓存第二份领导／占据数据，也不读取自由军团的未揭示忠诚或其他玩家手牌。

## 实现与验证

`piece-status.ts`复用引擎供应可用性；`pieces.ts`统一绘制全边／半边绿框并复用原版控制标记的徽记部分。`tabletop.ts`共用地区状态计算，`board-layout.ts`标注原地图人口／PV栏位方向。原版素材文件保持原样。

新增6项回归测试，覆盖四个历史剧本与教程的固定槽位、真实放置／移除影响力、部队移动／部署、共享MCS四种可用状态、撤销、并列军力及未揭示忠诚保密。全套463项测试通过，生产构建和Windows打包通过。

浏览器验证柏林影响力5/6→6/6时空位填满、民主联盟获得领导徽记，撤销后恢复5/6和并列状态；检查原版垫板绿框、地图原版地名与人口数字避让、可用与已部署棋子区分。构建和测试日志保存在本机`artifacts/`，不随Git同步。
