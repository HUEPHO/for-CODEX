# 实时 PV · 0.12

右上角的印刷选举区域说明被实时计票表覆盖，列出汉堡、慕尼黑、科隆、柏林、巴伐利亚、北部诸邦、南部诸邦、普鲁士诸省的四方 PV。金色底和星标表示该行最高值，正分并列时全部标记；全零行不标领先者。暗杀或起义导致整个区域停选时显示“停选”，四方均为零。

最后一行为全国总 PV，包含势头、中产支持、进步轨道及生效事件／剧本修正。底部 PV 规使用 TTS 原版四方 PV 标记显示同一组全国总值。同一刻度的标记错开摆放，不遮挡印刷数字；负分或超过40时停在相应端点，下方显示实际数值，表内也保留实际数值。

两处均由 `src/ui/pv-board.ts` 调用现有 `previewElection` 生成。它们显示当前公开局面的计票预览，不使用上一次选举结果，也不提前执行选票转让或议会控制变更。与原有顶部 PV 预览计算口径一致。每次行动、事件选择、撤销／重做、存档恢复和 Steam 快照都会重绘，无额外分数缓存或存档迁移。

新增四张原版 PV 贴图，原始字节和来源记录保存在 `public/assets/tokens/`。表格避开东普鲁士和经济轨道，地图各地区的印刷 PV 和领导徽记位置保持不变。

验证包含真实柏林放置影响力（区域0→6、联盟全国35→41）、撤销／重做／存档重放、势头只改变全国分、并列、两种停选、革命终局负分，以及房主命令执行后双方的实时 PV 一致性。

全套469项测试、类型检查、生产构建和Windows打包通过。浏览器实测柏林放置影响力及撤销，确认顶部、区域表与底部同步更新；生产页面无警告或错误，表格文字未越界且不遮挡东普鲁士。浏览器截图接口本次不可用，布局另以同一绘制代码生成的棋盘预览核对。日志和本机预览位于 `artifacts/`，不随Git同步。
