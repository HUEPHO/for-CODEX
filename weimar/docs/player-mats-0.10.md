# 原版玩家垫板 · 0.10

四个阵营使用TTS原版700×500垫板，不改印刷图；部队、中产支持、干部、罢工、杠杆、暗杀和集团是独立棋子。补入原版团结、立场及四枚即时胜利标记；声明胜利后标记从垫板移到主棋盘时间轴。

## 使用

点击顶部阵营名称直接展开对应玩家区，或展开棋盘下方的“玩家区 · 原版垫板与库存”。四个按钮切换公开垫板；“返回行动面板”回到操作区。切换垫板不会切换操作者，也不会显示该阵营的私有手牌。

垫板右侧列出影响力库存、可用／待解锁棋子、棋盘轨道上可取的标记和已移出游戏的部队。移出的部队不再算作待解锁库存。亮色库存棋子可用、淡色待解锁，依据现有引擎的可用性规则；教程和黑日升起的立场固定为务实并忽略立场解锁限制。即时胜利标记存在于垫板不代表已满足声明条件，声明仍通过原行动面板判断。

公开的团结、立场、杠杆及可用性随命令、事件、撤销或联机快照刷新。玩家区及内部库存明细在重绘后保持展开状态。垫板上不直接拖动或修改棋子。

## 代码与素材

- `src/ui/player-mats.ts`：原图坐标、公开状态映射、库存和垫板切换界面。
- `src/ui/player-mats.css`：桌面两列布局、窄窗口单列布局。
- `public/assets/mats/`：四张原图及来源清单；`public/assets/tokens/`：41张标记原图。
- `scripts/import-tokens.py --tts PATH/TS_Save_13.json`：读取TTS数据并导入两组素材，不执行Lua，保存原始图片字节、GUID、正反面、URL和SHA-256。运行游戏不需要下载远程图片。

公共棋盘与四块垫板上的棋子ID合计与所有未移出游戏的棋子一一对应。渲染只读取公开属性，不读取未揭示自由军团的忠诚；库存不读取手牌、牌堆或随机状态。存档格式与Steam协议保持兼容。
