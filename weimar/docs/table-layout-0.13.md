# 0.13 固定桌面布局

2026-10-22。按用户要求，将手牌放左侧、四个玩家的原版垫板列在右侧，主桌面适应窗口高度，减少滚轮操作。

## 使用方式

- 左侧显示自己的手牌，窗口高度决定每页4、6或8张；底部左右按钮翻页。点牌面放大，点“选用”同步到下方出牌栏。持续事件和有权查看的手牌使用独立标签。
- 右侧始终列出四张原版玩家垫板，保留实时团结、立场、经济影响力、棋子和绿框。当前行动者突出显示，联机时标明本人席位。点垫板放大，查看详细库存。
- 中间保留原版棋盘、实时PV及地区状态。底部以行动、地区、议会、战斗、记录五个标签切换；长内容可用上下按钮翻页。点地区查看详情，合法行动目标仍与执行栏联动。
- “收起”增加棋盘空间；“专注棋盘”隐藏下方操作区并保留左右两栏。棋盘放大后出现四个方向按钮，无需滚轮即可平移，使用“适应窗口”恢复。
- 对局与存档、Steam联机管理收在顶部菜单，展开时覆盖显示，不挤压桌面。

联机时，左侧依据本人的席位显示手牌，不跟随对手的行动回合切换；一人控制多方时可切换自己的手牌标签。公开手牌数量由房主投影提供，不用对手隐藏后的空手牌数组计数。本地热座在跨阵营待选时显示实际决定者的手牌。

## 验证

- 473项测试通过，新增4项覆盖棋子守恒、私有手牌／授权查看、分页及联机公开牌数。
- 在1280×720浏览器窗口中，页面尺寸与视口一致，左手牌、四张垫板和正常行动控件完整可见。验证手牌翻页、选牌同步、牌面放大、KPD垫板放大、详情标签及专注模式。
- 棋盘放大至125%后，向右按钮将水平位置移至191px；“适应窗口”恢复全图。
- 模拟Steam开局后切换到KPD，Coalition行动时仍显示KPD的7张手牌；四张公开垫板均显示，操作区提示等待Coalition。浏览器没有控制台错误。
- 生产构建、桌面类型检查和Windows x64打包通过。构建产物位于`release/win-unpacked/WEIMAR.exe`。
