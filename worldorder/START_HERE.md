## 最快运行

安装 Node.js 24，在解压后的 `world-order-codex` 文件夹打开终端：

```sh
npm run dev:local
```

浏览器打开终端显示的 `http://127.0.0.1:8787`。此入口无需先安装 npm 依赖，也不需要 Steam、Sites 登录或云数据库。

1. 创建房间，创建标签页默认扮演美国。
2. 使用大厅的中国、欧盟、俄罗斯入口，打开三个独立标签页并入座。
3. 房主开始，四方分别完成开局选择。
4. 后续在各自标签页操作；他方回应在对应标签页完成，刷新可恢复席位。

本地房间会保存，终端按 Ctrl+C 停止服务。普通静态文件服务器不能代替房间服务。需要 Vite 开发体验时，先执行 `npm ci`，再执行 `npm run dev`；详见运行文档。
