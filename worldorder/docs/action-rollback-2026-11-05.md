# 行动面板撤回 · 2026-11-05

行动面板常驻“撤回上一步”和“重新开始整个回合”，收起操作区时仍显示。整回合沿用本方一次行动的起点，包含连续出牌与后续结算，不是四家整轮。顶部旧入口也使用同一套权限与提示，选项统一为两种。

用户最新修订：抽牌、看过隐藏信息、揭标、随机事件结果等不再清除撤回快照。点击撤回即执行，并弹出“这不太好哟”；提示只保留关闭按钮，没有“仍然撤回”等二次确认。跨回合时点击即发送申请，仍须等待对方批准。只有跨过信息揭示的快照带提示；之后的普通单步撤回不会重复提示。

进入下一位玩家回合后，上一位玩家可以申请重开。对方行动面板显示申请者国旗及“同意重开／拒绝”，申请者可以取消。申请本身不改局面；同意后恢复上一位玩家行动开始时的完整服务器状态，也重置对方这期间的操作。申请者不能批准自己的请求，其他席位、过期请求、旧版本提交均不能替代对方同意。

继续提交游戏操作会使待处理请求失效；上一位玩家可基于更新后的局面再次申请。保留最近一次交接的重开起点，到下一次完整行动交接时更新；旧快照沿用30分钟有效期、最近12步上限。离座、接管席位、重新布置及 Debug Mode 清空相应快照和请求。旧存档仍可加载；此前版本已经丢弃的快照无法恢复。

服务端、Steam 权威房主和本地轮流操作共用快照与申请函数。房间下发的请求只有席位、状态和提示，不下发历史完整状态或身份凭证。确认请求经过操作版本检查和重复请求去重，成功恢复后各席位版本递增。未改动用户存档或在用房间。
