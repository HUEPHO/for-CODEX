# 地图、盟国商店与派遣操作 · 2026-11-05

## 本次确认

- 贸易使用 Smart Power 扩展地区时，点击该地区的盟国商店选择或取消，地图地区不再切换此项。
- 派遣时，左键地区从仓库放入1辆坦克，右键地区临时取回1辆。提交前可以调整，地图和右侧仓库数字同步预览。
- 临时取回的版图坦克必须重新派出，不能随提交留在仓库。派遣前的仓库基数包括本牌先获得或生产的坦克；不会误拦截这些正常奖励。
- 点击盟国商店的数字查看该堆全部盟国。左堆按等级升序，同级采用固定顺序以免暴露抽牌顺序；右堆按实际堆叠顺序从左到右展示，最底部在最右。

## 实现

- 军事增援及复用它的分段牌、建基地、快速反应部队、普通军事事件、协议后续移动、阿富汗强制重新部署共用派遣控件。事件要求先移至事件牌的承诺/计价表仍按该特殊目标填写，不将事件牌误作仓库。
- 派遣草稿按各地区的净变化编译为原有移动命令，原有移动次数、目的地、费用、SP、生产和归属校验继续生效。需要突破通常目的地限制时，预览显示每辆1 SP。
- 未重新派遣的临时取回会被预览和服务端拒绝，命令失败不扣费用、不消耗牌、不改局面。建基地仍要求至少1辆从仓库正常派出，最多用1 SP追加1辆。
- 联机新增只读的 publicCountryPiles 内容投影；左堆原始顺序仍脱敏，右堆允许查看实际顺序。他方手牌、目标和牌库继续使用原隐私规则。
- 牌堆数字独立于顶牌按钮，不会因查看列表选中贸易或结盟目标。浮窗定位从桌面顶部计算，避免长行动栏把窗口及关闭按钮推到屏幕外。
