# 盟国卡与贸易协定中文素材 · 审阅稿

用户要求先制作图片素材，审阅后再导入游戏，并明确选择“用程序批量替换文字”。本批没有修改 `dist/`、卡牌数据、游戏导入路径或已有存档。

本机交付目录：`output/中文卡牌审阅_2026-11-05/`。入口 `审阅.html` 支持按中文／英文国家名、地区及正反面筛选，每张并排展示原图和中文素材；`素材/` 为独立 PNG，`翻译对照.csv` 和 `素材清单.json` 记录翻译、原路径、图片尺寸及 SHA-256。

范围为现有 96 张盟国卡的正反面，以及四方各一张 Trade Deals：共 196 张 PNG，其中 179 张进行了文字替换，17 张起始盟国背面无英文、逐像素保留。包含 17 张起始盟国、76 张基础国家、朝鲜（2024）／乌克兰（2014）／英国三张扩展国家。Trade Deals 译为“贸易协定”，Exports / Imports 译为“出口 / 进口”；地区名沿用现有“美洲／欧洲／中亚／中东／非洲／南亚／亚太”。卡牌国家名称保留文字，年份不省略。

生成器：`scripts/build-chinese-card-review.mjs`，使用本机 authoring runtime 中的 sharp / Playwright 和 Microsoft YaHei 字体。只修补原英文及其阴影覆盖的像素，再写入中文；地图在文字覆盖处会有局部修补，保留其余图案、国旗、数字、资源图标与原始尺寸。该脚本不执行游戏导入。

用户补充要求字号加大、长名称除外：国家名常规字号由37增至52，地区名30增至38（以485像素宽正面为基准）；长名称按实测文字宽度缩小，波斯尼亚和黑塞哥维那保留两行。贸易协定的出口／进口及标题也同步加大。最新打包文件为 `output/中文卡牌审阅_2026-11-05_大字版.zip`。

验证：196 张图片尺寸与源图一致；17 张无英文背面的解码像素与源图完全相同；盟国文字区域外与贸易协定三个文字框之外的像素不变。已视觉检查全部正面和背面总览、长名称及扩展卡；审阅页搜索和筛选、原尺寸图片链接通过本机浏览器检查。

图片和 ZIP 按项目约定留在 `output/`，未提交到游戏源文件。等待用户审阅；收到导入指令后，再依据清单更新游戏素材与映射。
