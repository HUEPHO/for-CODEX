# 军事增援自动结算

四个势力的起始「军事增援」已核对牌面，支持先获得1待命军队，再进行0至2次移动，每次5资金。目的地限本方利益地区或本方已记录基地所在的盟国地区。来自地图的军队可以跨地区调动；第二步按第一步完成后的状态计算。所有选择在提交前预览，非法目的地、军队或资金不足均整体拒绝，成功后自动消耗卡牌并结束行动。

盟国卡可手动记录/移除已建基地。此按钮只记录已经自行结算的基地，不代替建基地行动，不扣费、不派兵、不增加影响力；并非对该国家是否允许建基地的自动验证。已有存档缺少bases字段时按空列表读取，记录第一个基地时自动补上。

特殊卡牌修正、SP附加效果和自动建基地仍未实现。

## 用户确认的计分解释

2026-09-15：影响力相同先比较军队，仍相同则拿较低名次奖励（两方并列第一都拿第二名分）。国家专属计分包含永久影响力槽未填满的区域。现有计分实现符合这两个案例；本次增加针对性检查和界面说明，不更改计分算法。

验证：check-military覆盖四张牌、先增援后移动、按顺序调动、基地通行、资金/军队不足的原子回滚、非法移动及行动轮转；check-basic-actions核对原有投资/介入/放弃行动未受影响。未进行浏览器验收。
