# 自动机事件选择策略 · 2026-11-06

用户第11页反馈高级自动机裁军无法确认，并要求尽量不让真人替自动机选择。高级与基础自动机现有 `nonPlayerChoice` 由服务端脚本处理。以下自由选择策略属于本实现策略，不是新增或已确认的印刷规则。

| 选择 | 脚本策略 |
| --- | --- |
| 裁军 | 承诺最少合法的1支实际版图军队。优先保持本方防御，其次保持对其他势力的威胁；平局从驻军较多的地区移回。协议达成之前只记录承诺，不提前移除或扣费。 |
| 撤军／增援 | 全部强制撤军进入合法目的地；高级沿用军事地区优先级，基础优先改善威胁状况与本方利益区。付费增援受实际资金限制。高级现有事件增援仍使用原军事优先级与抽牌判平；旧存档残留的选择按同一优先级、稳定地区顺序判平。 |
| 临时转永久 | 优先保留最早可能被挤出的临时影响力；平局优先本方利益区。 |
| 北溪 | 高级资金不足20时取得折现后的15资金，否则优先转永久；基础仅处理棋盘效果，选择转永久。没有可转换目标时沿用原事件处理。 |
| TTIP | 高级拥有至少30资金且在第1—3轮时选投资面，正常支付25资金；其余情况选交换面。基础选投资面但继续适用基础非玩家不支付／领取资源的规则。投资面的对方产能由持牌方选择，脚本选择未满级、相对稀缺且单位价值较高的资源；没有另加真人回应步骤。 |
| 金砖国家 | 高级按改善关系的优先级选择：升级起始盟国、允许建立本方基地、国家价值高。平局使用现有候选顺序。基础仍不取得国家奖励。 |

除已有高级军事抽牌判平之外，上表自由选择以既有地区／资源／候选顺序稳定判平，不额外查看或消耗未来牌序。TTIP产能选择依据两张投资面实图：持牌方支付并“提高欧盟／美国任一产能1点”，没有写为对方独立选择。

`nextAutomaticFlowAction` 在完整状态及脱敏视图中只生成不含目标的继续命令；`event-flow.js` 在权威状态中生成参数，再通过原协议／奖励执行器核对目标、数量、费用。客户端传入的自动机目标不会覆盖脚本结果。自动执行可以跨越原本的首位真人代理责任人，遇到真人自身的协议承诺或奖励选择仍停下。旧存档首次载入沿用现有自动继续入口，房间版本、席位、幂等和保存边界不变。

专项 `scripts/check-non-player-decisions.mjs` 覆盖单真人为中国的旧裁军待办、双真人跨责任人、北溪接续、七类选择、两种自动机、实际费用、协议未达成不裁军、脱敏视图不变、重试、旧版本与越权拒绝。原基础非玩家及高级WIT事件专项继续覆盖印刷出资与实际奖励。
