# 正式开局：发展牌数量与起始国家复核

本批接续 `eb82e0a`，修复新局发展牌供应。适用四名真人；不加入自动机、两人或三人规则。

## 已核对来源和修复

基础规则书第5页列出20张发展牌、17张起始国家、76张地图国家，第8页规定按牌名分堆；D&D第3页列出另20张发展牌，第18页说明替换和两种混合方法。已逐个读取原TTS存档的40个发展牌实体，确认第1级每种3张，第2～4级每种2张，第5级每种1张。

原导入脚本按“图片、格号、类型”去重，因此三份共用同一图片格的外交倡议只留下一个目录ID，基础供应误为18张；扩展10个目录ID也不代表只有10张实体。本次没有重跑导入、复制图片或改动原始存档。

`growth-setup.js` 显式保存实体数量。供应数组可重复相同牌面ID，每次只取走一份；各玩家独立拥有并应用效果，每人仍只能逐级购入。已有不同ID的同名牌继续保留其ID。

新房间／重新布置提供四种配置，全部20张，各级6／4／4／4／2：

- 基础：基础20张。
- 仅扩展：D&D20张。
- 每级随机两种能力：每级从四种能力中抽两种，加入该能力全部实体份数（D&D方案1，新开D&D房间的默认值）。
- 每级混洗抽取：同等级全部实体混洗，揭示规定份数，允许能力数量不均（D&D方案2）。

未启用D&D时始终使用基础。随机结果写入完整状态；刷新、加入、后续操作都不重抽。旧局不自动重建供应，缺少配置标记时大厅说明为原存档配置。

17张起始国家已逐图核对右上势力旗帜：美国墨西哥／伊拉克／日本／冰岛，中国南非／老挝／巴基斯坦／塔吉克斯坦，欧盟挪威／加拿大／约旦／尼日利亚／欧盟成员国，俄罗斯白俄罗斯／亚美尼亚／叙利亚／印度。原归属正确，欧盟5张、其他各4张。现有政权更迭对起始国家的保护继续沿用。

基础规则书第9页也确认：12起始能力分两组6张选一组；资产抽3留2，所选资产分数相加；首轮按分数降序，同分按起始资金升序。现有流程符合这些项目，不作改动。
