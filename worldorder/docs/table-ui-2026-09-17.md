## 实现导航

- `board-ui.js`／`board-ui.css` 只读渲染公开主板状态，不读取隐藏国家堆或手牌。
- `card-drag.js`／`card-drag.css` 通过 Pointer Events 处理鼠标和触屏拖动；开始与落下时检查合法性和局面版本，支持取消及拖动后点击抑制。落下只打开出牌设置。
- `table-selection.js`／`table-selection.css` 从现有表单的合法选项生成桌面可选目标，点选后写回原表单；不另建费用或目标规则。
- `app.js` 连接手牌、主板目标及右侧操作面板；`game-table.css` 负责桌面布局。真实结算和权限仍由原领域模块、动作策略与房间服务端校验。
- `index.html` 帮助说明已同步拖牌、点选目标、确认扣费及多人标签页流程。

## 维护要点

供给牌按一次遍历建立计数；高亮按目标Map查找，不逐卡运行出牌预检。拖动预检只在越过拖动阈值及落下时执行，不在每个指针移动中执行。切换展示区域保留操作表单节点；游戏或席位版本变化使旧表单失效。纯放大查看不重建盟国减费选项。
