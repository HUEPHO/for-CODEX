# 紧凑贸易窗口 · 2026-11-05

依据用户 `output/UI编辑-小窗口.pptx`，以及后续明确补充：所有资源的控件同时显示；选定贸易方向时用金框圈住该方向与库存；点击已选资源取消并清空该资源进出口。PPT 中的手机符号是消费品示例，所有贸易资源共用布局。

## 本地实现

- 贸易窗口按资源分列：玩家进口、盟国进口、图标与当前库存、出口。玩家进口数量按钮使用对应国旗作背景，数量显示为 `+已选/上限` 或 `−已选/上限`。
- 左键增加，右键减少，键盘上下方向键亦可调整；游戏页面禁止右键浏览器菜单。上限处继续增加不改变数值；零值不能再减。
- 选择进口后，金框包含该资源的进口选项和库存；选择出口后包含库存和出口选项。切换方向会清空该资源另一方向的待提交数量。
- 点击资源图标会取消其金框并清空本资源所有玩家进口、盟国进口和出口分配，其他资源的选择保留。减少到零仍可保留当前方向，点击图标明确取消。
- 表格是原表单输入的紧凑显示层，使用原贸易读取、容量、预览及实际结算。原输入和按钮的禁用权限仍有效，不另建费用或许可规则。
- 扩展选项与按地区分配出口保留；进入这些详细操作时收起数量区、保留库存图标，退出后恢复完整贸易表格。选项切换不清空已有数量。
- `AGENTS.md` 新增：如果有可能比用户命令更好的实现方案，可以提出。
