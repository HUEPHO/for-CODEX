# UI 编辑副本反馈与能源巨擘修正 · 2026-11-05

后续同日调整：按用户要求，行政命令已移至贸易信息同一行，顺序为专供出口商品卡、贸易协定、行政命令。启用行政命令时三列共用左侧可用宽度，商品卡与协定随窗口收缩；未启用时沿用两列布局。行政命令复用原按钮与权限，已使用状态继续显示。1440×900、1200×720 的同排、无横向溢出、点击与取消、已用／未启用状态检查通过；报告与预览位于 `.ui-pptx-build/executive-row/`。

本批依据用户提供的 `output/UI编辑副本.pptx` 四页修改及本轮文字补充。用户明确要求理解布局意图，不逐像素照搬。已检查修改后的四页及对应原始导出页。

## 界面

- 贸易协定图最大宽度 260px，与专供出口商品卡并排；未启用行政命令时整组最大宽度 702px，启用时按上述三列布局。发展与效果自然紧接下方，不保留 PPT 编辑过程产生的空白。
- 盟国卡改为约 104px 宽的紧凑排列，去除外围深色卡框。名称、地区、价值仍在卡下；原版翻面、叠牌、FDI／基地标记和点击入口沿用。
- 公共事件与个人事件各自固定两列。单张只占一列；两张一行，三／四张两行。原卡图、所属玩家、正在结算标识及详情入口保留，不改变事件槽位或结算规则。
- 中栏资产／手牌／行动与最右玩家栏保留现有固定布局。

## 能源巨擘

用户纠正：从能源或原材料中选一种，只有所选资源的盟国贸易符号计算两次。已复核原牌 `dist/assets/cee23aa848494.webp`。旧实现同时翻倍两种资源，且错误扩展到 SP 展示国家。

- 两套贸易表单共用二选一控件，初始选能源；可切换原材料。动作参数为 `primaryResource: 0 | 1`。
- 读取表单、额度预览、实际结算和整牌预检使用同一选择。实际执行拒绝缺失或无效选择，既有存档结构不变。
- 仅所选资源的盟国符号翻倍，包括叠在盟国下方的有效国家；SP 展示国家保持正常符号。
- 切换选择保留已填交易。若原数量超过新上限，显示错误并禁止结算，由玩家调整数量。
- 与欧亚经济联盟作用于同一出口符号时仍取 2 倍，不相乘；其他资源维持各自通常效果。
