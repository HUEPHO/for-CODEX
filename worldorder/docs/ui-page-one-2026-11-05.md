- 左侧滚动区依次为原版玩家面板、贸易协定及出口卡、发展与效果、盟国、完整原版主板、公共事件、个人事件、能力市场、发展商店。

- 原版玩家板保留七个 CSS 产能方块、焦点圆柱和繁荣环，裁去重复库存；主板下重复状态说明隐藏，必要成长修正提示保留。
