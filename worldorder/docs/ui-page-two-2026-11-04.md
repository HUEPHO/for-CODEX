# PPT 第二页与原版主板 · 2026-11-04

依据用户提供的新 `ui设计 - 副本.pptx` 第二页和两张游戏截图，沿用现有网页版及已确认的固定顶部、固定右栏、手牌随页滚动方式。

## 实现

- 左上为单独一行的大幅战略资产，下方手牌与行政命令；右上为原版动态玩家面板及实用信息。下方依次是原版主板、全宽公共事件、全宽个人事件、能力卡牌商店、常驻发展卡商店。能力市场仍按现有顺序新牌在左。
- 主板使用现有 `assets/map.webp`，坐标对应原版 2200×1964 图片；影响力、退役和额外槽、四方驻军、介入、轮次、顺序、分数及公开国家牌均从当前状态投影。原图商店只展示两张公开顶牌，不读取隐藏国家牌堆。
- 地图上的地区、槽位、国家牌继续通过现有表单和选择适配器操作；常驻发展商店复用同一选择表单和供应分组，选中不扣费，确认才结算。
- 盟国按参考卡片网格呈现，中文名称、地区、价值置于卡下。原版 FDI/基地透明图叠在牌面，宽约牌面 24%，不拦截点击；投资者名称与多个标记计数保留。消耗后显示原背面，融合保留叠牌。懒加载卡图预留原比例，避免首次滚入时零高度。
- 贸易协定使用现有四方原图，出口商品卡使用原 TTS 的四方正反面。可用、已使用和旧局未知状态分别显示正面、背面、带问号的背面。素材来源见 `references/original-map-token-sources.json`、`references/ally-marker-sources.json` 与 `references/trade-card-art-sources.json`。
- 页面重排仅移动现有按钮；战略资产、行政命令、对手公开详情及直接点击盟国减费保持原操作入口。能力/发展市场预留卡图比例，避免加载时页面跳动。

- 普通浏览器 1440×900、1200×720：布局顺序、顶栏/右栏固定、手牌滚动、无页面横向溢出、原图加载、库存与产能正常；重新加载保留原测试存档。
- 实际鼠标点击地图地区、临时影响槽、公开国家牌均正确更新原表单；选择时保存状态不变。

- 实际鼠标点盟国减免外交费、再次点取消、确认后消耗与翻背通过；卡片下信息与缩小标记单独视觉核对。
