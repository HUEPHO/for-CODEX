World Order 0.8 · HTML 网页版

Windows 开始游戏
1. 本机已展开的版本直接双击「启动网页版.cmd」。只有将 ZIP 拷贝到其他电脑时才需要先完整解压。
2. 游戏在默认浏览器中打开，通常为 http://127.0.0.1:8787 。无需 Electron、Steam 或安装其他软件。
3. 保持服务器窗口运行。按 Ctrl+C 或关闭该窗口停止服务。
不能直接双击 dist/index.html；网页通过 HTTP 加载模块与联机接口。

macOS / Linux 或自备 Node
安装 Node.js 24，在本包目录运行 npm start，无需 npm install；打开终端显示的网址。
网页前端位于 dist/，入口为 index.html。只上传静态文件可用本机桌面功能；多人房间还需要本包的 Node 服务及可写的数据目录。

同一台电脑测试四人房间
点击「创建／加入房间」，创建后由房主扮演美国。大厅中分别打开另外三个势力的新标签页入口，四方入座后开始。

同一局域网四台电脑
仅一台电脑运行服务器，另外三台只需浏览器。
在服务器电脑打开 PowerShell，进入本包目录，按实际局域网 IP 设置（示例 192.168.1.20）：
  $env:HOST='0.0.0.0'
  $env:PUBLIC_ORIGIN='http://192.168.1.20:8787'
  .\runtime\node.exe scripts\start-web.mjs
所有玩家（包括房主）都打开同一个 PUBLIC_ORIGIN 地址，再分享房间链接。Windows 若提示网络访问，请只按实际需要允许专用网络。不同网络的朋友需要另外部署 HTTPS 服务器；此包没有自动创建公网地址。

界面与操作
按新版 PPT 第一页，左侧从原版玩家面板、贸易协定/出口商品卡、发展牌与事件效果、盟国，向下排列原版世界主板、公共事件、个人事件、能力卡牌商店和发展卡商店。主板保持实时局面及目标选择。
右侧中栏固定战略资产、手牌与行动窗口；最右栏固定轮次和四方概况。战略资产每行两张，手牌每行三张，超过六张可翻页；行政命令在发展与效果区。
行动窗口没有内部滚动条，选牌后上方卡区缩为缩略图，保留盖牌选择。贸易通过资源标签编辑同一份交易，切换标签保留数量，确认后一起结算。
改善关系时可直接点击盟国选择减费，再点取消，确认后才扣费和翻到背面；融合盟国有金框和底牌叠放。
盟国卡下显示中文名称、地区与价值，FDI和基地使用缩小的原版标记；悬停可看投资者与数量。出口商品卡随使用状态翻面。
菜单可打开房间、操作说明、新对局和浏览器全屏。推荐使用电脑 Chrome / Edge / Firefox 的较新版本。
2026-11-04 图标更新：六种资源使用原 TTS 存档中的彩色实心透明图标，资源栏和贸易图标略微放大；刷新页面即可看到。

右上角显示四次行动进度圆点和“准备、行动、研究、事件、结算”阶段条；当前行动绿点、当前阶段金色。直接刷新已打开的网页即可使用本次更新，无需重新解压。

保存与身份
本机单桌进度保存在该浏览器、该网址的本地存储中。
联机房间与访客签名密钥保存在服务器数据目录，默认 .web/；WORLD_ORDER_DATA 可指定独立目录。
同一浏览器使用访客 Cookie，标签页另有席位令牌。刷新可恢复当前席位；清除 Cookie、使用隐身窗口或换浏览器会成为不同访客。
备份时先停止服务，再备份整个 .web/；不要单独删除其中的签名密钥。
本包不包含原桌面客户端的个人存档，旧客户端及其存档保留。

技术
HTML / CSS / 原生 JavaScript 前端，Node.js HTTP API + SQLite 房间服务；原有服务器操作校验、席位权限、隐藏信息脱敏和轮询同步保留。
这是可运行网页包，尚未部署到 Azure 或其他公网服务；联机服务器需持续运行。Steam 四人联机仍属于原桌面版本的独立模式。
