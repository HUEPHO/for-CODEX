# WIT 事件框架与首批自动结算 · 2026-09-16

后续更新见 [WIT混合竞价与事件影响力](wit-bids-2026-09-16.md)：新增6张自动事件及影响力规则。以下保留首批交付时的范围和验证。

本批在新局启用正式事件流程，保留旧存档原有的四方手动确认。未部署，也未重置已有本地或云端房间。

## 已实现

- 逐张核对60张中文事件牌图，录入名称、参与方、类型、地区和禁止延期标记。原目录把两时代整组标反：修正44张时代标记；现在时代I／II各22张，连锁16张。
- 开局抽到两张公共事件为止，首张放最右侧；个人事件分流，每方最多1张。开局重复个人事件弃置新牌；后续补充时由本人二选一，选择持久化并由该席位负责。
- 公共事件从右到左，随后按当轮顺序处理个人事件。允许的个人事件可在开始结算前支付1 SP延期；第6轮和三张禁止延期事件不允许。人工调整过效果后也不能再延期。
- 每张最多触发1张连锁；同一连锁只能加入一次。明确写有再次结算的平局例外另存，不与触发新连锁同时登记。下一轮先从左侧放连锁，再补至多两张时代事件；第3轮末抽时代II。
- 阿拉伯之春、抵抗轴心崛起揭示时立即替换；抵抗轴心中立影响力按用户裁定先填空永久槽，满后进入临时队列。克罗地亚揭示时检索并重洗国家牌；阿富汗事件揭示时由美国、欧盟分别选择至多2次正常付费移动，付费不足整次提交回滚。
- 新事件面板显示公共槽、个人事件、连锁、已弃置牌和逐牌账目。自动事件期间锁定额外资源修改；人工事件仍可登记资源、产能、繁荣及地图变化，完成者不可追加调整。
- 新局仅使用新流程；没有 `eventVersion` 的旧存档不迁移、不重新抽牌、不补发效果。

## 自动效果范围

| 事件 | 自动部分 |
| --- | --- |
| 萨赫勒人道主义危机 | 选择援助次数，校验10资金＋1粮食每次，发2外交＋1 SP，外交超限舍弃 |

| 全球去美元化举措 | 外交秘密投标，美国资金修正；全员提交后同时扣费、公开投标、计算胜败SP与牌面奖励；全零无修正时无效果，未投标获胜方不拿本方奖励 |
| 明斯克协议 | 双方公开提案，均正贡献且合计恰好5外交才达成；结算双方分数/SP，否则不扣外交并触发入侵乌克兰。移除已登记的对俄制裁标记；持续效果及实体牌仍须人工维护 |

其余53张非转折点事件仍是明确标示的逐牌人工结算，不宣称60张全部自动化。一般竞价所需的军队、资金组合与多数效果尚未接入。原目录17条“效果牌”实际上含14张持续效果牌及3张替换国家，持续效果、国家替换和事件移除／转换影响力仍待开发；尤其不可把旧地图手动移除的普通空槽当成已经实现WIT的“起始槽永久忽略”规则。

## 实际验证

- `node scripts/check-events.mjs`：60张元数据／时代、80种开局牌库守恒、个人分流、公共顺序、最低值与资金等值边界、真实成本、资源上限、秘密提交与刷新恢复、平局／零投标、协议恰好5、单一连锁与重复例外、延期、时代切换、揭示军队移动、克罗地亚检索、中立影响力、人工繁荣及已结算保护、房间私密视图／重复提交／撤销限制。
- `node scripts/check-flow.mjs`、`check-room-game.mjs`：基础版和扩展版均完成六轮及终局；扩展版现在经过新逐牌事件流程。人工牌在这些程序检查中按未执行选项确认，因此不是所有牌面效果的验收。
- `check-state.mjs`、`check-setup-stock.mjs`、`check-rooms.mjs`、`check-phase-framework.mjs`通过。后两者保留旧事件存档场景，确认兼容而非为了旧断言退回旧规则。
- 独立端口8798、独立SQLite测试房间 `WTEV44`：四个实际浏览器席位提交美1／中2／俄1秘密投标，美国资金40修正＋2；结果3比3，美国赢。提交前资源未扣、未显示对方出价；揭晓后账目正确且最后提交不能撤销，刷新恢复。
- 同一浏览器测试继续全球金融危机：四方产能均1、繁荣0。美国资金40仅跳过无法降低的产能；中／欧／俄资金0，各仍扣2分并继续。随后俄罗斯支付1 SP延期个人事件，补牌时选择保留旧事件并弃新事件，成功进入余波。
- 截图核对了第5轮事件区的三个公共槽与个人事件显示。测试使用人工准备的局面，未声称从开局连续真人试玩六轮。

## 代码与后续

`event-data.js`为核对后的60牌数据；`event-board.js`管理牌库、分流、揭示和连锁；`event-flow.js`管理责任玩家、协议／秘密投标及逐牌结算；`event-ui.js`提供界面。通过现有引擎原子提交、阶段、房间去重／权限／脱敏接口接入，无独立状态后门。

下一批优先做通用竞价成本及事件影响力变化，再逐组接入其余事件和持续效果；需要新规则裁定时集中询问。不要恢复研究阶段主动抽换牌，也不要把战役优势推迟到第4轮。
