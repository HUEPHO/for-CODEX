# WIT 个人事件与持续贸易效果 · 2026-09-16

本批新增5张自动个人事件及2张持续效果。当前共23张非转折点事件自动结算、2张转折点即时处理；仍有35张事件、12张持续效果、3张替换国家待实现。本地可运行，未部署。

## 本批牌面

| 事件 | 已实现的完整路径 |
| --- | --- |
| 亚洲基础设施投资银行（AIIB） | 先检查至少50资金。可放弃，或付2外交重整一个尚未投资的本方盟国，正常付投资费用、横置、放FDI并添加影响力。支持通常的投资后付1 SP重整、区域韧性；结果和历史保存所投国家 |

## 持续效果与存档

- 欧亚经济联盟：俄罗斯贸易时，亚美尼亚、白俄罗斯、哈萨克斯坦、吉尔吉斯斯坦的出口符号计算两次。进口符号不受该效果影响；叠放的起始国家贸易符号继续有效。用户后续裁定：与能源巨擘作用于同一能源／原料出口符号时仍为2倍，同类翻倍不叠加。此前相乘实现已修正并加入回归。兼容原始目录中吉尔吉斯斯坦的 `Kyrgystan` 拼写。
- CAFTA：中国贸易时自动计入南亚、亚太当前展示国家。沿用禁交旗帜和牌面地区限制，与SP／卡牌提供的相同地区去重；界面不再让玩家为这两个已免费开放的地区额外花SP。它不改变盟国归属、盟国数量或其他行动的条件。
- `eventEffects`独立记录效果所属玩家、来源事件和获得轮次；只由已实际执行的事件发放，不把效果牌目录或旧手工标记直接当作已生效效果。旧局正在人工结算的同名事件继续人工处理，避免重复扣费／领奖。
- 可选支付在前端显示具体费用并预检，服务端仍完整校验。不足或非法目标时整次提交回滚；放弃与延期是不同选择。事件完成后不能再重复提交或事后延期。
- 随机连锁仅在服务器接受提交时抽取，预览不抽取；结果和事件历史持久化。命令重试不重抽。房间揭晓后不可撤销，本地桌面也清除跨过随机揭晓的撤销路径。
- 事件区、玩家面板和贸易界面均显示已生效的效果；AIIB结算记录可查看本次投资的国家。

## 实际验证

- `node scripts/check-event-personal.mjs`：五张事件的条件成功／失败、执行／放弃／延期、费用不足完整回滚、投资与SP、影响力位置、军队来源与费用、三个随机连锁、全部连锁已出现、效果归属与去重、贸易容量与地区限制、刷新恢复、旧人工存档、席位权限、重复请求及随机揭晓撤销保护。
- `check-trade.mjs`、`check-events.mjs`、`check-event-bids-advanced.mjs`通过，复核共用贸易、事件生命周期和竞价撤销保护。原人工多连锁检查明确使用旧存档模式，没有把新自动事件改回人工以迁就断言。
- `check-flow.mjs`／`check-room-game.mjs`通过基础和扩展六轮程序流程；未实现的事件仍以人工确认推进，因此不代表全部牌面已完成。
- 独立端口8799、独立SQLite，使用三个浏览器席位完成以下路径，没有改动普通本地房间：
  - `EDC555`：美国付10资金移入2军队，获2 SP，随机抽到美国—日本—韩国同盟，刷新仍相同且撤销禁用；中国凭泰国获2 SP及CAFTA、登记RCEP；俄罗斯凭两指定盟国减到0外交，付10资金／2能源后取得2 SP、中亚永久影响力及持续效果。随后进入余波，两个连锁出现在下一轮个人事件区。
  - `EDC556`：中国以50资金起步，给已横置泰国执行AIIB，付15资金／2外交，投资后再付1 SP重整。刷新后泰国保留FDI且未横置；俄罗斯凭土耳其免外交，出售数量6被界面拒绝，改为5后付10、收入25，正常进入余波。
  - `EFA555`：复制已完成事件的测试状态至第4轮行动起点。中国贸易显示CAFTA免费容量，实际出口2能源而不扣SP；俄罗斯界面显示EAEU后的8个消费品出口符号，实际出口2消费品获得30资金并结束行动。此处验证后续动作接入，不是从事件连续经过整个余波推进。
- 浏览器检查是准备局面的代表路径，不是从开局连续真人玩六轮。测试房间保留在隔离目录，测试服务在验收后停止。
