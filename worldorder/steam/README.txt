World Order — Steam 四人联机

开始游戏
1. 四台 Windows 10/11 64位电脑分别安装 Steam，并登录不同账号；与房主互加 Steam 好友。
2. 每台电脑将整个压缩包解压，双击 Start-Steam.bat。浏览器自动打开本机游戏页面。
3. 房主点击“创建 Steam 房间”，复制大厅中的数字房间号发给其他三人。
4. 其他人输入房间号加入，各选一个势力；房主点击“四人就绪，开始选牌”。

不用安装 Node.js，不用 npm install，不用配置公网服务器。程序只在本机监听网页，游戏消息经 Steam P2P 传输。
如果浏览器没有自动打开，使用启动窗口显示的完整地址，包括 # 后的本机令牌。
邀请朋友时只发数字房间号，不要发 127.0.0.1 地址或本机令牌。

如果提示“原生组件加载失败”或缺少 VCRUNTIME140.dll，请先确认完整解压，然后安装/修复微软 Visual C++ v14 x64 运行库并重启启动器。
微软官方下载：https://aka.ms/vc14/vc_redist.x64.exe
说明：https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
本包未附带或自动安装这个系统运行库。

对局与恢复
保持 Steam 和启动窗口运行。刷新浏览器会恢复当前账号的席位。
客机掉线后重连原房间，可找回该账号的席位。网络短暂中断时操作暂停。
房主退出程序或离开 Steam 房间时，本局停止；当前版本不迁移房主。
“退出 Steam 房间”保留该账号在原对局的席位，便于稍后重新加入。
顶部“撤回…”支持上一步、本阶段、本方完整行动；抽牌、揭示信息或他方接续操作后不能跨节点撤回。
自动快照最多保留最近12步及阶段/行动起点，30分钟过期，不提供手动存档管理。

当前验证范围
已实现四人会话、席位隐私、权威结算、回执重试、刷新/客机重连、断线暂停与撤回接入。
程序检查使用真实游戏引擎和模拟Steam通道；Windows原生模块已实际加载成功。
当前开发电脑不能登录Steam，尚未完成四个真实Steam账号跨网络实测。

依赖与示例应用
本版使用 steamworks.js 0.4.0 的 Reliable P2P 接口，AppID 480（Steam的Spacewar示例应用）。
在Steam中可能显示为Spacewar；这不是正式上架的独立Steam应用。
使用的第三方许可位于 steam/licenses。原版游戏素材属于各自权利人。

开发版本
有 Node.js 24 的开发者可以在项目根目录运行 node scripts/start-steam.mjs。
原有本机四标签页模式仍通过 node scripts/dev-local.mjs 启动，两个模式使用不同的数据目录。
